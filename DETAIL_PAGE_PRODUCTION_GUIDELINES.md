# Detail Page Production Guidelines

These rules are mandatory for every first draft and revision in the shared Figma
file `AI 생성 상세페이지`.

## Product Truth And Image Sources

- Treat verified 1688 images as the source of truth for silhouette, tier count,
  components, option colors, dimensions, scale, and supported uses.
- Use a deliberate mix of supplier images and generated images. Supplier images
  prove the actual product; generated images add clean cover or lifestyle scenes
  only when they preserve that product exactly.
- Assign each image one purpose. Do not repeat the same supplier crop, AI scene,
  pose, or camera angle across meaningful sections.
- Chinese copy must not remain in final visual output. Never cover Chinese copy
  with a rectangle and place Korean text above it. Use a clean crop, a text-free
  supplier crop, or a product-faithful regenerated image instead.

## Required Sequence

1. Create a strong, text-clean cover showing the actual product, Korean product
   name, and one factual USP. Never use a raw supplier banner or an awkward crop.
2. Immediately after the cover and before `CHECK POINT 01`, add the Marbin-style
   option table. Each real option gets a clear card, verified visual, option name,
   and a short evidence-backed description. Do not replace this with a fact card.
3. Build feature and lifestyle sections with visually distinct, product-faithful
   scenes. Do not pad page height with duplicate images or empty space.
4. Add Size Info before product information. Center a background-removed product
   cutout on the section and show only verified width, height, and depth guides.
   A full rectangular supplier image is not acceptable as Size Info.
5. Keep the fixed seven-line caution block immediately before the supplied
   Funtastic IP notice image. Product-specific cautions may follow the seven
   fixed lines, but must not replace them.

## Visual Direction

- Use the approved card-news plus USP hybrid layout.
- Use at least three coordinated but clearly differentiated colors. Establish
  contrast intentionally across sections; do not repeat one near-identical
  brown, beige, or mint family from top to bottom.
- Use readable spacing: no overlap, no clipped text, no oversized empty areas,
  and no filler panels that merely repeat the copy above.
- Target 12,000 px or more with meaningful visual and factual content.

## Review Gate

Before moving a job to review, capture the whole frame and key sections. Confirm
product fidelity, the supplier-plus-AI image mix, no Chinese copy or patch boxes,
cover quality, option table placement, transparent size cutout, three-color
variation, fixed notices, IP notice, 12,000 px height, and sensible spacing.
Store this result as a concise Korean QA report. Any failed item means the draft
must stay out of user review.
