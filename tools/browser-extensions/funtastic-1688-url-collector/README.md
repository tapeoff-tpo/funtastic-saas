# Funtastic 1688 URL Collector

## 설치

1. 이 폴더를 로컬에 둡니다.
2. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다. 두 Chromium 브라우저를 공식 지원합니다.
3. 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드합니다`를 선택합니다.
4. 이 폴더를 지정한 뒤 Funtastic SaaS 품목 화면을 새로고침합니다.

## 동작

- 폴더에 `order-queue.json`이 있으면 네 개 발주 엑셀에서 만든 주문번호 전체를 우선 사용합니다.
- 주문번호 접두어로 1688 계정을 추측하지 않고 현재 로그인된 계정에서 모든 번호를 순서대로 조회합니다.
- 확장프로그램은 로그인된 1688 주문조회 화면을 주문번호별로 순회하고 상품 영역을 열어 상세주소를 확인합니다.
- 각 결과가 SaaS에 저장됐다는 확인을 받은 뒤 다음 주문으로 이동합니다.
- 중단하거나 브라우저를 다시 열어도 최대 최근 9건만 재확인하고 저장 지점부터 이어갑니다.
- 미발견·복수 링크·저장 오류는 전체 순회가 끝날 때까지 누적합니다.
- 기존 구매 URL은 덮어쓰지 않습니다.

## 발주 송장 자동조회

- SaaS `발주 > 구매완료`의 `1688 송장 일괄조회`는 페이지·선택 여부와 관계없이 구매완료 전체에서 주문서번호가 있고 송장이 아직 없는 행을 조회합니다. 이미 송장·검수 기록이 있는 행과 주문서번호가 없는 행은 건너뜁니다. 같은 주문번호의 상품은 묶어서 한 번만 조회하고, 진행 창에서 대상 상품 수와 고유 주문 수를 구분해 표시합니다.
- 각 주문 상세에서 물류 탭을 직접 열어 `运单号码` 라벨의 값만 운송장번호로 읽습니다. `物流编号` 같은 물류 식별값은 저장하지 않습니다. 1.10.1부터 SaaS는 `运单号码` 라벨을 실제로 확인한 추출 결과만 저장하며, 구형 확장 결과는 저장하지 않습니다.
- 이미 `LP...` 물류번호가 잘못 저장된 미검수 행은 SaaS `검수` 탭의 `1688 송장 다시 수집`으로 실제 `运单号码`만 남기도록 다시 조회할 수 있습니다. 박스·수량 검수가 시작된 행은 자동으로 바꾸지 않습니다.
- `物流`, `物流信息(1)`, `查看物流详情` 등 물류 탭 표기 변형과 열려 있는 shadow DOM을 함께 탐색하고, 물류 정보가 늦게 표시되는 주문은 추가로 기다린 뒤 판정합니다.
- 1.11.0부터 주문 문서가 준비되는 즉시 수집을 시작하며, 전체 페이지의 이미지·분석 요청 완료를 기다리지 않습니다. 각 프레임은 즉시 현재 값만 반환하고 재확인은 확장프로그램에서 진행해, 내용이 없는 iframe과 비활성 탭의 타이머 때문에 정상 조회가 매번 오래 대기하지 않습니다.
- 1.12.0부터 같은 일괄조회 작업에서 서로 다른 주문을 최대 3개 탭으로 동시에 조회합니다. 먼저 끝난 주문부터 저장하고 다음 주문을 시작합니다. 주문별 상태·제한시간·결과는 따로 관리하며, 같은 주문번호의 상품은 한 번만 조회합니다. 기존 확장에서는 순차 조회를 유지하므로 동시 조회를 사용하려면 확장을 업데이트하고 SaaS 화면을 새로고침해주세요.
- 진행 창에서 중지하면 이미 진행 중인 주문의 조회·저장을 마친 뒤 중지합니다. 진행 창 자체를 닫으면 해당 창이 연 조회 탭과 제한시간을 정리합니다. URL 수집·URL 검증·이미지 수집과 송장 조회는 동시에 실행하지 않습니다.
- `1688 송장 일괄조회`의 진행 목록은 SaaS 별도 창으로 열립니다. 실제 1688 주문 상세는 일반 브라우저 탭으로 열며, 일괄조회 중에는 비활성 탭으로 열어 SaaS 진행 창의 포커스를 빼앗지 않습니다. 로그인·보안 확인이 필요한 탭은 닫지 않고 남겨두며, 사용자가 해당 탭에서 확인한 뒤 다시 시작할 수 있습니다.
- 조회된 송장번호는 기존 검수 흐름으로 저장되므로 해당 행은 `검수` 단계로 이동합니다. 여러 송장은 함께 등록됩니다.
- 이미 수동으로 등록한 송장이나 검수 정보는 덮어쓰지 않습니다.
- 로그인 만료나 보안 확인은 일괄조회를 멈추고, 아직 발송 전·주문 확인 불가 건은 화면에 사유를 표시한 뒤 다음 주문을 조회합니다.

## URL 검증

- 품목 화면의 `URL 검증`은 이미 등록된 1688 구매 URL을 실제 로그인된 1688 화면에서 하나씩 엽니다.
- 결과는 `정상 열림`, `상품 없음`, `확인 필요`로 나뉩니다. 로그인 또는 1688 보안 확인이 나오면 자동으로 우회하지 않고 작업을 멈춥니다.
- 중단하거나 브라우저를 다시 열어도 마지막 확인 지점부터 이어집니다. URL 자체나 품목 정보는 변경하지 않습니다.
