# Funtastic 쿠팡 등록 확장

쿠팡상품등록의 2단계에서 만든 견적서 1개와 품질표시 JPG/PNG를 현재 Chrome의 서플라이어허브 로그인 세션에 연결합니다. 주문 수집 확장·RPA와 독립된 기능이며 비밀번호·로그인 쿠키를 읽거나 서버로 보내지 않습니다.

## 설치

1. 이 폴더를 D드라이브에 보관합니다. SaaS에서 받은 ZIP은 압축을 풀어 사용합니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드합니다`로 이 폴더를 선택합니다.
3. SaaS 쿠팡상품등록 페이지를 새로고침합니다. 기존 1688/소싱 확장과 별도로 설치합니다.

## 등록과 결과 확인

- 2단계에서 상품 정보를 저장하고 `상품등록`을 누릅니다. 하나의 작업에는 XLSX 1개만 포함할 수 있습니다. 등록 상품명도 서로 달라야 결과를 정확히 연결할 수 있습니다.
- 확장이 새 서플라이어허브 창을 열어 견적서와 품질표시를 선택합니다. 이 화면에서 가격·라벨 연락처 선언을 직접 읽고 체크하고, 상품에 필요한 법정서류를 첨부하거나 해당 여부를 직접 선택합니다.
- 준비 후 확장 패널의 `선언·필수서류 확인 후 검증 시작`을 누르면 활성화된 `파일 검증하기`를 한 번 누릅니다. 확장은 선언을 대신 동의하거나 법정서류가 불필요하다고 판단하지 않습니다.
- 쿠팡 검증은 최대 2시간이 걸릴 수 있습니다. SaaS의 결과 확인으로 재확인합니다. 확장이 보관한 기존 작업은 새로 업로드하지 않습니다.
- 등록완료는 고유한 견적서 파일명으로 전체 견적서 ID가 확인되고, 상품 목록에서 **견적서 ID·상품명·SKU ID·상품 검수 완료**가 모든 상품에 정확히 일치할 때만 반영됩니다. 축약된 견적서 ID만 있으면 확인 필요로 유지합니다. `검수중`은 계속 2단계에 남고, 일부 반려는 이미 처리된 상품의 재업로드를 막기 위해 진행 상태를 유지합니다. 모든 요청 상품의 반려가 정확히 확인된 경우에만 실패로 종료합니다.
- Chrome을 다시 열어도 대기 작업은 로컬 확장 저장소에 남습니다. 처음 등록한 Chrome에서 결과를 확인해주세요. 확장을 삭제하면 이 로컬 기록은 사라집니다.

## 중복·화면 변경 처리

이미 선택된 파일, 동일한 파일명의 여러 견적서, 바뀐 업로드 화면, 다른 상품 수, 비어 있는 SKU, 결과 불명은 자동 완료하거나 재업로드하지 않습니다. 서플라이어허브에서 상태를 확인한 뒤 SaaS의 결과 확인을 사용합니다. 확장 재설치나 로컬 저장소 삭제 후에는 같은 작업을 새로 업로드하지 말고 쿠팡의 기존 견적서 상태부터 확인해주세요.

접근 범위는 SaaS 운영 주소, 로컬 개발 주소 3000/3001, `supplier.coupang.com`뿐입니다. 법정서류는 확장에서 수집하지 않으며 Hub에서 직접 첨부합니다. 확장 저장소에는 제출 파일과 작업 식별값이 있으므로 공유 PC에서는 해당 Chrome 프로필 접근을 관리해주세요.

## 공식 카테고리 검색·양식 연결 (1.1.0)

- SaaS가 B2B 상품의 분류와 검색어를 보내면 로그인된 서플라이어허브의 공식 카테고리 검색에서 후보를 가져옵니다. 저장한 견적서 목록과 별도로 조회합니다.
- 검색 후보를 선택하면 해당 카테고리의 공식 ZIP/XLSX 양식만 내려받아 SaaS에 전달합니다. 상품등록·파일 검증·선언 동의는 실행하지 않습니다.
- 검색은 최대 6개 검색어, 결과는 유효한 최종 분류 50개까지 반환합니다. 상품에 맞는 분류는 후보 경로를 확인하고 선택해주세요. 결과가 없으면 분류명이나 상품 종류를 바꿔 검색합니다.
- 기존 등록 탭이 없으면 비활성 서플라이어허브 탭을 엽니다. 로그인 안내가 나오면 해당 탭에서 로그인한 뒤 다시 검색해주세요. 로그인 쿠키·비밀번호를 읽거나 SaaS로 보내지 않습니다.
- 공식 양식 파일은 3MB까지 연결할 수 있습니다. 확장을 업데이트한 뒤 Chrome 확장 관리에서 새로고침하고 SaaS와 허브 페이지를 새로고침해주세요.
